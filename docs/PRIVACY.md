# OnAir Privacy Policy

**Last updated**: May 6, 2026
**Effective date**: May 6, 2026

## Plain-language summary

OnAir is built privacy-first. We've designed it to keep your meetings on your
Mac and minimize what leaves your computer.

**What stays on your Mac**:
- All audio recordings of your meetings
- Transcriptions (generated locally by OpenAI Whisper running on your Mac)
- Meeting metadata (start/end times, durations, statistics)
- Your settings and preferences

**What can leave your Mac (only if you choose)**:
- Transcribed text sent to Anthropic's Claude API to generate a summary
  (only if you select Claude as your summary backend and configure your own
  API key)

**What always leaves your Mac**:
- Anonymous update checks to GitHub (to know if a new version is available)

**What never leaves your Mac**:
- Audio recordings (always stay local, even with the Claude backend)
- Your API keys (stored in macOS Keychain, never transmitted to us)
- Personal information about you

**We don't collect analytics, telemetry, or usage data.** We don't have
servers that store your data. We don't track you.

If you use the Ollama backend instead of Claude, **nothing about your meetings
ever leaves your Mac**.

## 2. What data OnAir handles

### 2.1 Locally on your Mac

OnAir stores the following data on your Mac, in
`~/Library/Application Support/OnAir/` and the macOS Keychain:

- **Audio recordings**: WAV files of meetings you choose to record (Pro only)
- **Transcriptions**: text generated by OpenAI Whisper running locally
- **AI summaries**: structured summaries generated by Claude or Ollama
- **Meeting metadata**: timestamps, durations, platforms detected, statistics
- **App preferences**: your settings, including which monitoring options
  are active
- **Anthropic API key**: stored encrypted in macOS Keychain (only if you
  use the Claude backend)

These files are protected by your macOS user account and your Keychain.
We don't have access to them.

### 2.2 Data that leaves your Mac

**OnAir does not have any servers**. We don't receive any of your data.

The following data leaves your Mac depending on your configuration:

#### When you generate a summary with Claude (optional)

If you configure OnAir to use Anthropic's Claude API, OnAir sends to Anthropic:

- The transcribed text of the meeting (in clear text, over HTTPS)
- A prompt asking for a structured summary
- Your Anthropic API key (in the request header, as required by the API)

The transcription is sent **as text**, never as audio. Anthropic processes
the request and returns a summary. We refer you to
[Anthropic's Privacy Policy](https://www.anthropic.com/legal/privacy) for
details on how they handle this data.

You are entering into a direct relationship with Anthropic when you
configure your API key. OnAir is not party to that relationship.

#### When you generate a summary with Ollama (optional)

If you choose Ollama as your backend, OnAir sends the transcription to the
Ollama server you configured. By default, this is `http://localhost:11434`
(your own Mac), so **nothing leaves your computer**.

If you configure Ollama to point to a remote server (e.g. another machine
on your network), the transcription is sent there. That's your decision
and outside OnAir's scope.

#### When OnAir checks for updates

OnAir periodically checks GitHub for new releases (using the Sparkle
update framework). This consists of an HTTPS GET request to
`https://github.com/OnAirApp/OnAir-releases/...` to download a small
XML file listing available versions.

**What GitHub sees**:
- Your IP address (visible in their server logs)
- Your User-Agent (e.g. "Sparkle/2.x macOS/14.x")
- The fact that an OnAir installation checked for updates

**What GitHub does not see**:
- Any unique identifier tied to you
- Any data about your meetings or usage

We don't transmit any system profile information (Sparkle's
`sendsSystemProfile` is disabled).

You can disable update checks in macOS System Settings → Network if you
want to prevent this.

## 3. How long we keep your data

Since we don't have servers, **we don't keep your data at all**. Your data
lives on your Mac, under your control.

OnAir's local data retention is configurable:

- **Audio recordings**: deleted according to `recording_retention_days`
  (default 30 days, configurable to immediate deletion via Settings)
- **Transcriptions and summaries**: kept indefinitely in OnAir's local
  database until you delete them via the Statistics window
- **Settings**: kept until you uninstall OnAir or delete the config file

If you uninstall OnAir, you can delete all data manually:

```
~/Library/Application Support/OnAir/
~/Library/Logs/OnAir.log
```

And remove the API key from Keychain via Keychain Access.app (search for
"com.solucor.OnAir").

## 5. Your rights

Depending on where you live, you have the following rights:

### Right of access
You already have full access to your data — it's on your Mac. You can
browse files in `~/Library/Application Support/OnAir/` and view summaries
in OnAir's Statistics window.

### Right of rectification
You can edit summaries directly in the OnAir interface (Edit button in
the Meeting Notes view). Audio files and transcriptions are read-only by
design (to preserve their integrity), but you can delete them.

### Right of erasure
You can delete data at any time:
- **Individual meetings**: in the Statistics window, select a meeting and
  delete it
- **All data**: quit OnAir and delete `~/Library/Application Support/OnAir/`
- **API key**: Settings → API Key → Remove, or delete the entry from
  Keychain Access

### Right to portability
Meeting summaries can be copied/exported via the Meeting Notes window
(Copy button). The underlying database is a SQLite file at
`~/Library/Application Support/OnAir/meetings.sqlite` and can be opened
with any SQLite tool.

### Right to object / withdraw consent
You can stop using OnAir at any time. There's no account to delete because
we never had one to begin with.

### Right to lodge a complaint
- **In Quebec**: file a complaint with the Commission d'accès à
  l'information du Québec (https://www.cai.gouv.qc.ca/)
- **In Canada**: file a complaint with the Office of the Privacy
  Commissioner of Canada (https://www.priv.gc.ca/)
- **In the EU**: contact your national data protection authority
  (list at https://edpb.europa.eu/about-edpb/about-edpb/members_en)

## 6. Security

OnAir uses macOS native security features:

- **Keychain**: your Anthropic API key is stored in the macOS Keychain,
  encrypted by your operating system
- **HTTPS**: all network requests (Anthropic API, GitHub update checks)
  use TLS encryption
- **Code signing**: OnAir is signed with Apple's Developer ID and notarized,
  preventing tampering
- **Sandboxing**: OnAir runs as a regular macOS application with the
  permissions you grant (microphone, camera detection, accessibility for
  meeting detection)

We don't store any of your data ourselves, so we can't lose, leak, or
mishandle it.
